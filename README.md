# Landing Page

Цей проєкт — адаптивна лендінг-сторінка компанії, створена для презентації бренду, продукції та контактної інформації. Сторінка має чистий мінімалістичний дизайн, побудований за макетом з Figma, і реалізована з використанням сучасних веб-технологій.

🛠️ Технології

HTML5 — семантична розмітка сторінки

SCSS / CSS3 — стилізація, міксини, адаптивність

Flexbox / Grid — для побудови сітки контенту

Git + GitHub — для контролю версій та хостингу
