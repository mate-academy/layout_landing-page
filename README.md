# Landing Page

## Project Description

Responsive landing page created during the Mate Academy Front-end course. The project follows semantic HTML principles, BEM methodology, and adaptive layout.

## Technologies Used

- HTML5
- CSS3
- SCSS
- JavaScript
- BEM methodology
- Git
- GitHub

## Getting Started

1. Clone the repository:

``bash
git clone https://github.com/dannydan0311-glitch/layout_landing-page.git
``

2. Navigate to the project folder:

``bash
cd layout_landing-page
``

3. Instal dependencies:

``bash
npm instal
``

4. Start the developing server:

``bash
npm start
``
