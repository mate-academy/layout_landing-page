# MYBIKE Landing Page

A responsive landing page for the MYBIKE brand.
The page includes a hero section, product comparison, details section, contact form, navigation menu, and footer image effect.

## Technologies Used

- HTML5
- SCSS / Sass
- BEM methodology
- CSS Grid
- Flexbox
- Responsive design
- Mixins
