The project is a landing page made according to the selected layout MyBike. It is a page which illustrates a modern bike shop. It has header, main content with examples of bikes, contacts and footer. It also has an aside menu to navigate the page.
To complete the project, besides using HTML and CSS, I used the following technologies and methodologies: Flexbox, BEM, preprocessor Sass, variuos CSS animations and transformations, Grid. To see the design I also used Figma.

- [DEMO LINK](https://V4NY0K.github.io/layout_landing-page/)
- [MYBIKE landing](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)


To start the project make sure to clone the repo, run 'npm i', open it in IDE (VSCode) and run 'npm start'.
