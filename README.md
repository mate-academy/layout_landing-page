# Landing Page
A fully responsive landing page built with HTML5, SCSS (BEM), and Flexbox/Grid based on a Figma layout.

## 🛠 Technologies Used

* **HTML5** — semantic structure and accessibility
* **CSS3 / SCSS (Sass)** — variables, mixins, BEM architecture, Flexbox, and CSS Grid
* **Git & GitHub** — version control and deployment

## 💻 Run Locally
To run this project locally, clone the repository using `git clone https://github.com/Inna2424/layout_landing-page.git`, navigate into the project directory with `cd <repository_name>`, install the required dependencies by running `npm install`, and launch the local development server with `npm start`.
