# MyBike Landing Page

A modern, responsive landing page for the MyBike brand, featuring smooth scrolling, interactive hover effects, and a sleek design. This project was built to practice layout skills, BEM methodology, and responsive web design.

## Technologies Used
- **HTML5**: Semantic layout.
- **SCSS**: Styling using variables, mixins, and BEM architecture.
- **Vite**: Fast frontend build tool.
- **JavaScript**: Used for basic interactions.

## Setup Instructions

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm start
   ```
   The site will be available at `http://localhost:5173/` (or another port specified by Vite).

4. **Lint and format code:**
   ```bash
   npm run lint
   ```
5. **Build for production:**
   ```bash
   npm run build
   ```

## Features
- Fully responsive across mobile, tablet, and desktop.
- Custom sticky scroll reveal footer.
- Smooth anchor navigation between sections.
- Form inputs with clear placeholder instructions and native HTML validation.
