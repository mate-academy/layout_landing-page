## Про проєкт

Це навчальний проєкт, створений в рамках курсу в Mate Academy. Метою було зверстати адаптивну лендінгову сторінку на основі наданого макету з Figma.

### Технології

- **HTML5**: для створення семантичної структури сторінки.
- **SCSS**: для стилізації з використанням змінних, міксинів та вкладеності для кращої організації коду.
- **BEM**: методологія для іменування класів, що робить код більш читабельним та масштабованим.
- **Flexbox & Grid**: для створення адаптивних розкладок.
