-About the project

This project is a responsive landing page created based on a Figma design. It adapts to different screen sizes, including desktop, tablet, and mobile devices.

-Technologies Used

HTML5

SCSS (Sass)

CSS Grid and Flexbox

BEM methodology

Git and GitHub

Demo: https://osi634.github.io/layout_landing-page/#
Figma Design: https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f&t=gEcpFrbZ8DZ9ofTH-0

To run this project locally, follow these steps:

git clone https://github.com/OSI634/layout_landing-page

cd layout_landing-page

npm install

npm start
