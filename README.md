# Landing Page "Nothing"

Сучасний адаптивний лендінг, розроблений з використанням підходу mobile-first. Проєкт має модульну архітектуру стилів та чистий код.

## Технології

- **HTML5**
- **SCSS** (модульна структура файлів, використання змінних та міксинів)
- **Методологія BEM**
- **CSS Grid / Flexbox**
