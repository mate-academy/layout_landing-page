# Bang & Olufsen — Landing Page

A responsive landing page built from a Figma design, showcasing Bang & Olufsen speakers and headphones: a hero section, a recommended products grid, categories, a brand story section, and a contact form.

## Live demo

- [Demo](https://proninamariia.github.io/layout_landing-page/)
- [Mockup (Figma)](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6817-212)

## Technologies used

- HTML5
- Sass (SCSS)
- Vanilla JavaScript
- Intersection Observer API for scroll-in animations

## Core features

- Responsive layout with a slide-in mobile menu
- Smooth scrolling to page sections from the menu
- Scroll-triggered reveal animations with a single consistent transition duration
- Contact form with required fields, an email format check and a phone number pattern, plus inline validation messages
- Optimized WebP images with a dedicated mobile image for the About section

## Setup instructions

```bash
npm install
npm start       # local dev server
npm run build   # production build
npm run deploy  # deploy to GitHub Pages
```
