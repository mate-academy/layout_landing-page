# Landing Page

> ❗❗ You will complete this task in the **Landing** topic.
> Now just choose a design and do the parts from the videos.
> Note: in the first task of this topic you will find 4 examples of landing pages. Choose **only one** of them and create your page.

Project Overview
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.
- **Off-Canvas Menu:** A hidden sidebar navigation accessed via a hamburger icon.
- **CSS Grid Layout:** Used for creating complex, masonry-like layouts in the **"The details"** section.
- **Product Catalog:** A section dedicated to comparing different bike models.
- **Contact Form:** A functional contact section for customer inquiries.

Technologies Used
- SCSS
- CSS Grid
- BEM
