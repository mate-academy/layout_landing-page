# Landing Page Project

This is a landing page project for Nothing company, built with modern web technologies. It features a responsive design and a clean layout optimized for conversions.

## Technologies Used

- HTML5
- CSS3
- Sass
- BEM

## How to start

1. Clone the project repository.
2. Install dependencies with `npm install`.
3. Start the project with `npm start`.
