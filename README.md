# MYBIKE Landing

Responsive landing page based on the MYBIKE Figma design. The project includes a hero section, compare bikes cards, detailed feature blocks, a contact form, burger navigation, and a sticky footer.

## Technologies

- HTML5
- SCSS
- Vite
- JavaScript

## Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm start
   ```
3. Build the project:
   ```bash
   npm run build
   ```
4. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```
