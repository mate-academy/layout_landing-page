# Landing Page

This project is a responsive landing page designed to present a company’s brand, products, and contact information. It focuses on semantic HTML structure, modular SCSS styling, and modern build tools for deployment.

Technologies Used
HTML5 — semantic markup

SCSS (BEM methodology) — modular and maintainable styling

JavaScript (ES6+) — interactive functionality

Parcel — bundler and deployment tool

Project Structure
src/ — source files (HTML, SCSS, JS)

dist/ — production build output

package.json — project configuration and scripts

How to Run Locally
Clone the repository:

bash
git clone https://github.com/dianakerekesha/layout_landing-page.git
Navigate into the project folder:

bash
cd layout_landing-page
Install dependencies:

bash
npm install
Start the development server:

bash
npm start
Build for production:

bash
npm run build
