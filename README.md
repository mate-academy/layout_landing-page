# Nothing Landing Page

Адаптивний лендинг бренду Nothing, створений за макетом Figma.
Містить товари, категорії, інформацію про компанію та контактну форму.

## Використані технології та інструменти

- HTML5 — структура та семантика сторінки.
- SCSS — стилі, змінні та міксини.
- BEM — методологія іменування CSS-класів.
- Flexbox і CSS Grid — розташування елементів.
- Git — контроль версій.
- GitHub — зберігання репозиторію.

## Локальний запуск

Для запуску потрібні Node.js та npm.

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/eduard-sukhomlyn/layout_landing-page.git
   ```

2. Перейдіть до папки проєкту:

   ```bash
   cd layout_landing-page
   ```

3. Встановіть залежності:

   ```bash
   npm install
   ```

4. Запустіть сервер розробки:

   ```bash
   npm start
   ```

## Збірка та перевірки

Створити збірку для публікації:

```bash
npm run build
```

Перевірити та автоматично відформатувати код:

```bash
npm run lint
```

Запустити тести:

```bash
npm run test
```
