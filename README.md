# THE MET Landing Page

A responsive landing page based on The Metropolitan Museum of Art design from the Mate Academy landing-page project. The page includes museum hours, current exhibitions, online exploration cards, contact information, responsive navigation, interactive states, and a contact form layout.

## Technologies

- HTML5
- SCSS / Sass
- BEM methodology
- Flexbox
- CSS Grid
- Responsive design
- Parcel

## Run locally

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open the local URL shown by Parcel in the terminal.

## Notes

The contact form currently uses native browser validation. To actually deliver submitted messages, connect the form to a backend or a form service and replace the placeholder `action="#"` with the real endpoint.
