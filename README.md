короткий опис проєкту:
  MYBIKE — це адаптивна лендінг-сторінка, створена для демонстрації сучасних електровелосипедів.
Проєкт реалізований за принципами responsive design, використовує сітку, міксіни та змінні SCSS для зручного масштабування стилів.

технології, які було використано:
  HTML5 — семантична структура сторінки
  SCSS (SASS) — модульна стилізація з міксінами, змінними та адаптивною версткою
  BEM — методологія для іменування класів
