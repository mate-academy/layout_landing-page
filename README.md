# Bang & Olufsen — Landing Page

A responsive landing page for the Bang & Olufsen brand, built as a practice project.

## Technologies

- HTML5
- SCSS (variables, mixins, nesting, etc.)
- CSS Grid & Flexbox
- BEM methodology

## Preview

[Live Demo](https://azesmmisha.github.io/layout_landing-page/)

## Running locally

Requires **Node.js v20.20.2**

```bash
npm install
npm start
```
