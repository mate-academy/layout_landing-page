# The MET - Landing Page

Landing page responsiva desenvolvida para o museu **The MET (The Metropolitan Museum of Art)** como parte do currículo da Mate Academy.

## Tecnologias Utilizadas
- HTML5 (semântica e acessibilidade)
- Sass / SCSS (BEM e arquitetura modular)
- Vite
