# Nothing (R) Landing Page

A landing page inspired by the Nothing brand design, developed as a project for Mate Academy.

## Technologies used

- HTML5 — semantic markup with BEM methodology
- SCSS — variables, mixins, nesting, @for loops
- CSS Grid and Flexbox — responsive layouts
- CSS Animations and Transitions — hover effects and animations
- CSS :target — JavaScript-free menu overlay
- Responsive Design — mobile, tablet and desktop breakpoints
- Google Fonts — Space Grotesk, Space Mono, Inter
- GitHub Pages — deployment

## Preview

[Live Demo](https://carvalhoryahn-alt.github.io/layout_landing-page/)

## Layout

[Figma Design](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6802-139)

## How to run

```bash
npm install
npm start
```
