# MyBike Landing Page

## Brief Project Description

MyBike is a responsive landing page for an electric bicycle brand.  
The website showcases a range of bicycle models, highlights key technical features such as automatic locking, extended battery range, and hydraulic suspension, and includes a contact section for customer inquiries.

## Technologies Used

- HTML5 (semantic markup)
- CSS3
- SCSS / Sass
- BEM methodology
- JavaScript
- Google Fonts (Poppins)
- ESLint
- Stylelint
- Prettier

## Features

- Responsive mobile-first layout
- Burger menu with anchor-based navigation
- Smooth scrolling between sections
- Semantic HTML5 structure
- Modular SCSS architecture (blocks, utils, helpers)
