## About

This project is the Mate Academy `Landing Page` task implemented with the
`MYBIKE` design. The page includes:

- responsive layout for mobile, tablet, and desktop
- smooth anchor navigation
- mobile menu with scroll lock and sticky top bar
- clickable phone, email, and Google Maps address links
- image hover scaling with consistent animation timing
- form reset on submit without page reload
- sticky footer background effect
