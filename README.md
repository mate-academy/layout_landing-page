## 🛠️ Технології

* **HTML5** === Семантика
* **SCSS / SASS** === BEM-методологія, міксини та змінні
* **Flexbox & CSS Grid** === Адаптивна верстка
* **Чистий CSS** === Для реалізації :target меню, position: sticky та transform: scale()`
* **TinyJpg** === Усі зображення оптимізовано для швидкого завантаження сторінки.

## ⚙️ Додаткові Інструкції для Запуску

Щоб запустити проєкт локально:

1.  Клонуйте репозиторій:

    git clone [https://github.com/Nazarii-Lesniak/layout_landing-page/tree/develop]

2.  Перейдіть до директорії проєкту.
3.  Відкрийте файл `index.html` у браузері або використовуйте Live Server, якщо ви використовуєте VS Code.
