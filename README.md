# Bang & Olufsen Landing Page

## Description

Responsive landing page created based on a design mockup.
The project demonstrates semantic HTML, SCSS structure, and modern layout techniques.

## Technologies used

- HTML5
- SCSS (Sass)
- BEM methodology
- CSS Grid & Flexbox
- Responsive design (mobile-first)
