# MyBike Landing Page

## 📝 Project Description
A responsive landing page for a bicycle store. The project was developed as part of the Mate Academy curriculum to demonstrate advanced layout techniques.

## 🛠 Technologies Used
* **HTML5** (Semantics)
* **SASS/SCSS** (Variables, and mixins)
* **BEM Methodology**
* **Flexbox** (Responsive grid system)
