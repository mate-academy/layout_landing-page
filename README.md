The frontend of the home page for the "Bang & Olufsen" shop. The page includes a header, a side menu, and 4 sections: "recommended", "categories", "about us", and "contact us". The page is fully responsive with a mobile-first approach.

Technologies used:
 - HTML5
 - Saas (SCSS)
