# MYBIKE Landing Page

A responsive landing page built from scratch using semantic HTML and SCSS (BEM methodology), based on the **MYBIKE** design.

**Live Demo:** [MYBIKE Landing Page](https://ratushnjakivanko-spec.github.io/layout_landing-page/)

## Design Reference

[MYBIKE landing — Figma](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## Technologies Used

**Core**
- HTML5
- SCSS (BEM methodology)
- JavaScript — Small interactive behaviors (e.g. slider, mobile menu)

**Development & Deployment**
- ESLint / Stylelint — Code quality
- GitHub Pages — Hosting and deployment

## Getting Started

1. Clone the repository:

```
git clone https://github.com/ratushnjakivanko-spec/layout_landing-page.git
cd layout_landing-page
```

2. Install dependencies:

```
npm install
```

3. Run the project locally:

```
npm start
```

## Features

- **Responsive Design:** Optimized for different screen sizes and devices.
- **BEM Methodology:** Styles are structured using the BEM naming convention for maintainability.
- **Pixel-Perfect Layout:** Built block by block following the MYBIKE Figma reference.
