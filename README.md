Product Landing Page

A responsive product landing page built with HTML, SCSS, and JavaScript. The project focuses on translating a modern design into a clean, structured, and responsive web experience across desktop, tablet, and mobile devices.

Technologies

Getting Started

To run the project locally, follow these steps.

Prerequisites

Make sure you have the following installed:

* Node.js
* npm (included with Node.js)
* Git

Installation

1. Clone the repository:

git clone https://github.com/ParubokMotornyi/layout_landing-page.git

2. Navigate to the project directory:

cd layout_landing-page

3. Install dependencies:

npm install

4. Start the development server:

npm start

5. Open the local URL displayed in your terminal.

Production Build

To create a production build, run:

npm run build
