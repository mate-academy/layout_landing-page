# Landing Page Layout

Responsive landing page implementation from Figma design — built as part of Mate Academy HTML + CSS Advanced module.

## 🚀 Live Demo

🔗 https://kaida-iryna.github.io/layout_landing-page/

## 🛠 Tech Stack

- HTML5 (semantic markup)
- SCSS (Sass)
- BEM methodology
- Flexbox + responsive web design

## 📚 What I learned

- BEM naming convention for scalable CSS
- Sass nesting, variables, mixins, and partials
- Hero section + sticky navigation
- Responsive breakpoints (mobile-first)
- Hover states and smooth transitions

## 🏃 Run locally

```bash
git clone https://github.com/kaida-iryna/layout_landing-page.git
cd layout_landing-page
# Open index.html in browser
```
