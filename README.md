# MYBIKE Landing Page

A responsive landing page for a bike company created using HTML and SCSS.

The project was developed based on the Figma design and includes responsive layouts for mobile, tablet, and desktop screens.
BEM methodology, Flexbox, and CSS Grid were used for building reusable and structured components.

## Technologies Used

- HTML5
- SCSS (Sass)
- BEM methodology
- Flexbox
- CSS Grid
- Parcel Bundler
- Responsive Web Design
