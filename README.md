# MyBiKE Landing Page

A responsive landing page for MyBiKE, featuring product highlights, bike comparisons, details, and a contact form.

## Technologies

- HTML
- SCSS (Sass)
- JavaScript
- Vite

## Run locally

Requirements: Node.js and npm.

1. Install dependencies:

   ```sh
   npm install
   ```

2. Start the development server:

   ```sh
   npm run start
   ```

3. Open the local URL printed by Vite in your terminal.

To create a production build:

```sh
npm run build
```
