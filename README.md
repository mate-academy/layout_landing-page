# Landing Page
MyBike — Landing Page
Опис проєкту:
Сторінка містить шапку з навігацією та мобільним меню, головний банер, секції з описом переваг товару, деталями продукту та порівнянням моделей велосипедів. Вёрстка виконана відповідно до макета, з підтримкою мобільної, планшетної та десктопної версій
Технології:
HTML5 — семантична розмітка
SCSS/CSS3 — Flexbox, CSS Grid, BEM-методологія, адаптивна верстка.
