# MyBike Landing Page

A modern, responsive landing page for an online bicycle store showcasing bike models, details, and contact information.

## 🔗 Live Demo

[View Live Demo](https://toshka7313.github.io/layout_landing-page/)

## 🛠 Technologies Used

* **HTML5** — semantic markup structure
* **CSS3 / Sass (SCSS)** — modular and maintainable styling
* **BEM Methodology** — clean, scalable CSS class naming convention
* **Responsive Web Design** — adaptive layout for desktop, tablet, and mobile viewports

## ✨ Features

* **Adaptive Layout:** Seamless display across different screen sizes (mobile, tablet, desktop)
* **Interactive Navigation:** Smooth scrolling to page sections and a responsive mobile burger menu
* **Product Showcase:** Structured cards displaying bike models, specifications, and pricing
* **Contact Form:** Interactive form with field validation for customer inquiries

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/toshka7313/layout_landing-page.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd layout_landing-page
   ```

3. **Install dependencies** (if using a bundler/task runner):
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```
