# Landing Page — The MET

Односторінковий лендінг музею [The Metropolitan Museum of Art](https://www.metmuseum.org/) за макетом THE MET: години роботи, виставки, онлайн-ресурси та форма зворотного зв’язку.

## Technologies

- HTML5
- SCSS
- Vite (`@mate-academy/scripts`)
- Vanilla JavaScript (scroll reveal)

## Preview

[THE MET — Figma](https://www.figma.com/file/lSR1m42L9YwzQwzzxKwHpw/THE-MET)

## Getting started

```bash
npm install
npm start
```

Інші команди:

- `npm run build` — production-збірка
- `npm run deploy` — деплой на GitHub Pages
- `npm test` — лінтери та тести
