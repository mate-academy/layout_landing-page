# Nothing Landing Page

Responsive landing page based on the Nothing design from Figma. The page includes a hero section with a burger menu, recommended products, product categories, an "About us" block and a contact form.

## Demo

[DEMO](https://ketrinya.github.io/layout_landing-page/)

## Design

[Figma mockup](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6802-139&t=L7eKz5YKLN0m5WxR-0)

## Technologies

- HTML5 (semantic markup)
- SCSS with BEM methodology
- CSS Grid and Flexbox

## Features

- Responsive layout for mobile, tablet and desktop without horizontal scroll
- Burger menu built with CSS only (`:target`)
- Smooth scrolling and hover/focus effects with a single animation speed
- Phone, email and address are real links (`tel:`, `mailto:`, Google Maps)
- Contact form with required fields and reset on submit
- Optimized images (WebP backgrounds, compressed PNG, lazy loading): page weight reduced from ~3.7 MB to ~0.8 MB

## Getting started

    npm install
    npm start
