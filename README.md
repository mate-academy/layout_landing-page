# MyBike

## Project description

MyBike is a responsive landing page for a modern city bike. The website includes a navigation header, hero section, bike information, contact form and responsive design for different screen sizes.

## Technologies

- HTML5
- SCSS (Sass)
- BEM methodology
- CSS Flexbox
- CSS Grid
- Responsive design
