# ⚡ Nothing Landing Page

Landing page responsiva e moderna desenvolvida com base no design conceitual da marca Nothing (via Figma). O projeto enfatiza semântica HTML5, fidelidade visual, acessibilidade, navegação suave e boas práticas com SCSS e metodologia BEM.

## 🛠 Tecnologias Utilizadas
- HTML5 Semântico
- SCSS / SASS (Arquitetura modular e BEM)
- CSS Grid (12-column grid) & Flexbox
- JavaScript Vanilla
