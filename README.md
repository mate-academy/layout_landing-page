# Bang & Olufsen Landing Page

A responsive landing page for Bang & Olufsen audio products, built with HTML and SCSS.

## Live Preview

[slysahex.github.io/layout_landing-page](https://slysahex.github.io/layout_landing-page/)

## Design Reference

[Figma design (B&O)](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6817-212&t=ZTV6Gl8NzaWkJ4FK-0)

## Technologies Used

- HTML5
- SCSS (variables, partials)
- BEM methodology
- Flexbox and CSS Grid
- Responsive layout: mobile, tablet, desktop
- Google Fonts (Manrope)

## Features

- Responsive layout for mobile, tablet and desktop
- Burger menu without JavaScript (CSS checkbox)
- Smooth navigation to page sections
- Product sections: recommended products and categories
- Contact form with required fields; it resets after submit
- Clickable phone, email and address links

## Getting Started

```bash
git clone https://github.com/slysahex/layout_landing-page.git
cd layout_landing-page
npm install
npm start
```
