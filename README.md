Project Description

This project is a responsive landing page built based on a design mockup .
The main goal was to accurately reproduce the layout, ensure responsiveness across devices, and follow modern frontend best practices.

The page includes structured sections, reusable components, and clean styling architecture using SCSS. Special attention was given to layout consistency, code organization, and maintainability.

---

Technologies Used

* **HTML5** — semantic markup
* **SCSS (Sass)** — variables, mixins, nesting
* **CSS Flexbox & Grid** — for layout and alignment
* **Node.js & npm** — project environment and dependency management
