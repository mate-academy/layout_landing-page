# MyBike Landing Page

  ## Project Description
    Responsive landing page for MyBike brand.
    The page includes adaptive layout, smooth navigation, interactive menu, and form validation according to the checklist requirements.

  ## Technologies Used
    - HTML5
    - SCSS (Sass)
    - BEM methodology
    - Vite
    - JavaScript (basic)
    - Git & GitHub

  ## Live Preview

## How to Run the Project Locally

1. Clone the repository:

git clone https://github.com/fedechkova/layout_landing-page.git

2. Install dependencies:

npm install

3. Run the project:

npm start
