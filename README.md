# Bang & Olufsen Landing Page

A responsive landing page based on the Bang & Olufsen design from Mate Academy. It presents recommended audio products, product categories, the brand story, and contact information.

- [DEMO LINK](https://hulkovskyi.github.io/layout_landing-page/)
- [Figma design](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6817-211)

## Technologies

HTML, SCSS, JavaScript, and Vite. The styles use BEM naming, CSS Grid, and Flexbox. The layout adapts to phone, tablet, and desktop widths.

## Run locally

Use Node.js 20 and npm.

```sh
npm install
npm start
```

Open the URL printed in the terminal to preview the site locally.

Run `npm run lint` to check HTML and SCSS, or `npm run build` to create the static site in `dist/`.

The contact form opens a prefilled draft in your email app when you submit it.
