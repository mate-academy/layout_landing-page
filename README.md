# Nothing Landing Page

A responsive landing page based on the Nothing design from Figma. The project showcases modern web layout techniques, responsive design, and clean user interface implementation.

## Live Preview

🔗 https://maksymivivan2000-dotcom.github.io/layout_landing-page/

## Design Reference

🔗 https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6802-139&t=L7eKz5YKLN0m5WxR-0

## Technologies Used

* HTML5
* SCSS (Sass)
* JavaScript (ES6+)
* BEM methodology
* Git & GitHub

## Getting Started

### Clone the repository

```bash
git clone https://github.com/maksymivivan2000-dotcom/layout_landing-page.git
cd layout_landing-page
```

### Install dependencies

```bash
npm install
```

### Run the project locally

```bash
npm start
```

## Features

* Responsive layout
* Semantic HTML structure
* SCSS architecture
* BEM naming convention
