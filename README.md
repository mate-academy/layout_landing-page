## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/mybike.git
   ```

2. Navigate to the project folder:
   ```bash
   cd mybike
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```
