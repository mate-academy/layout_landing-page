# Nothing Landing Page

A responsive landing page for Nothing products based on a Figma design. The project includes a header with navigation, product recommendations, categories, about us, contacts section, and footer.

## Technologies Used:
HTML5
SCSS (Sass)
BEM methodology
CSS Grid
Flexbox
Parcel

## ##Getting Started:
1. Clone the repository
git clone https://github.com/YOUR_USERNAME/layout_landing-page.git
cd layout_nothing-landing-page
2. Install dependencies
npm install
3. Run the project locally
npm start
4. Build the project
npm run build

## Features:
Responsive layout for mobile, tablet, and desktop
Semantic HTML structure
BEM naming convention
CSS Grid and Flexbox layouts
Interactive hover and focus states
Smooth transitions and animations
