# MyBike Landing Page

A responsive landing page for **MyBike**, an urban e-bike brand. The page presents the product story, bike comparison cards, feature details, and a contact section in a clean portfolio-ready layout.

The project focuses on semantic HTML, BEM-style class naming, modular SCSS architecture, responsive grids, smooth navigation, and polished hover interactions.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Fullscreen hero section with branded navigation
- Slide-in menu with smooth anchor navigation
- Product comparison section
- Feature gallery with adaptive image proportions
- Contact form with required fields
- Clickable phone, email, and map links
- Sticky visual footer effect

## Getting Started

Make sure you have **Node.js 20+** installed.

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm start
```

Build for production:

```bash
npm run build
```

Run code quality checks:

```bash
npm run lint
```

Run tests:

```bash
npm test
```
