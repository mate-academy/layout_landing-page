# Landing Page - The MET

Landing page for The Metropolitan Museum of Art (The MET), built with modern web development technologies. The project features responsive design with support for mobile devices, tablets, and desktops.

## Project Description

A single-page website for The MET museum, which includes:
- Main hero section with welcome message
- Information about museum hours
- Gallery of current exhibitions
- Section for exploring collections online
- Contact form and location information

## Technologies

- **HTML5** - semantic markup
- **SCSS/Sass** - CSS preprocessor with BEM methodology
- **CSS Grid & Flexbox** - for responsive layout
- **Responsive Design** - support for mobile, tablet, and desktop devices
- **Google Fonts** - typography (Cinzel, Roboto)

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/olitm/layout_landing-page.git
```

2. Navigate to the project directory:
```bash
cd layout_landing-page
```

3. Install dependencies (if applicable):
```bash
npm install
```

4. Run the project locally:
```bash
npm start
```
or simply open the `index.html` file in your browser.

## Features

- Responsive layout with three breakpoints (mobile, tablet, desktop)
- Modular SCSS file structure
- Reusable mixins for common styles
- Navigation menu with smooth animations
- Optimized images and icons
- Accessible contact form
