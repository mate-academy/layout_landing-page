# Landing Page

Адаптивна односторінкова landing page для Метрополітен-музею. Реалізує дизайн із Figma з використанням семантичної розмітки, BEM-методології та SCSS.

Технології:
  HTML5
  SCSS / CSS3
  BEM
  Responsive Design
  Webpack / Parcel

Інструкції для запуску:
  # 1. Клонувати репозиторій
git clone https://github.com/ptrodion/layout_landing-page.git

# 2. Перейти до директорії проєкту
cd layout_landing-page

# 3. Встановити залежності
npm install

# 4. Запустити локальний сервер розробки
npm start

# 5. Зібрати продакшн-білд
npm run build
