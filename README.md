# Bang & Olufsen Landing Page

## Опис
Адаптивна лендинг-сторінка аудіо-бренду Bang & Olufsen. Реалізовано повну адаптивність (Mobile First), інтерактивне мобільне меню, плавну навігацію та валідацію форм.

## Технології
- HTML5, SCSS (BEM)
- JavaScript (ES6+)
- Git, GitHub Pages
- Vite (збірка)

1. `npm install`
2. `npm start`
3. Відкрити http://localhost:5173
