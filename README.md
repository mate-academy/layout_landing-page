# Project Description
This project is a responsive landing page built based on a Figma design.
The page includes multiple sections such as header, categories, recommended products, about us, and contacts.

# Technologies Used
- HTML5
- SCSS (Sass)
- BEM methodology
- Responsive layout (mobile, tablet, desktop)
- CSS Grid & Flexbox

# How to Run the Project
1. Clone the repository:
   `git clone https://github.com/Sofiia912/layout_landing-page.git`
2. Open the project folder
3. Run index.html in your browser
