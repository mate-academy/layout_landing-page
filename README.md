# MyBiKE Landing Page

A responsive landing page for MyBiKE, built from the selected design.

- **Preview:** https://deniskovvall-hub.github.io/layout_landing-page/
- **Design:** [MyBiKE Figma](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## Technologies

HTML, SCSS, GRID, BEM

## Run locally

```sh
git clone https://github.com/deniskovvall-hub/layout_landing-page.git
cd layout_landing-page
npm install
npm start
```
