# My Bike

A landing page for a bike shop, built from a Figma design using semantic HTML, SCSS and the BEM methodology.

## Technologies

- HTML
- SCSS
- BEM
- Git

## Demo

[Live demo](https://DaniilDanilyuk.github.io/layout_landing-page/)

## Figma

[MYBIKE landing](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## Getting started

```bash
git clone https://github.com/DaniilDanilyuk/layout_landing-page.git
cd layout_landing-page
npm install
npm start
```
