# 🖼️ Description

A museum website featuring four main sections: **About Us**, **Now on View**, **Explore Online**, and **Contacts**.

The header includes the museum logo, navigation menu, phone buttons, and a welcoming message.

The menu provides links to each section of the website and displays contact phone numbers.

The **About Us** section contains information about the museum’s schedule.

The **Now on View** section showcases current exhibitions with photos and titles.

The **Explore Online** section highlights three digital options or products offered by The MET.

The **Contacts** section includes a contact form and two museum addresses with phone numbers and exact locations.

The footer features a single background image.

# 🛠️ Technologies Used
1. HTML5 semantic structure;
2. BEM methodology;
3. Sass (SCSS) preprocessor;
4. CSS Grid layout;
5. Positioning (sticky, relative, z-index);
6. Adaptive design (mobile first approach);
7. SCSS variables and mixins for breakpoints, colors, hover effects;
8. Hover effect and transitions.
