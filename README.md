# Landing Page - Nothing

This project is a Landing Page layout for the Nothing technology brand, based on the provided Figma design.

- [Figma](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6802-139&p=f&t=DzIfoXWYMzn4OTjb-0)

🛠️ Technologies and Approaches
Languages: HTML5, SCSS/Sass - Semantic markup and CSS preprocessor for styles.
Methodology: BEM (Block, Element, Modifier) - Clear and modular class naming system.
Layout: CSS Grid, Flexbox - CSS Grid for modular grid creation (6-column layout) and Flexbox for internal element alignment.
Focus: Responsiveness, Accessibility - Ensuring correct display across different devices and interactive state handling.

💡 Solved Technical Challenges
Several important tasks were solved during the project regarding stability and user experience:
🔧 Eliminating Layout Shift on :hover
Solved the content shifting problem when hovering over input fields. Achieved by using border: 1px solid transparent; in the base state, which reserved space for the border without changing the overall element height.
🎨 Placeholder Styling
Configured precise placeholder (::placeholder) styling with color change on hover and focus, ensuring design consistency.
