# MYBIKE landing

## Short description of the project

The page is designed with a responsive layout that adapts to the screens of both desktop and mobile devices.
Hover effects add dynamism to the user experience.

### Screen Adaptations:

+ Desktop >1260px
+ Tablet >744px
+ Mobile >320px
