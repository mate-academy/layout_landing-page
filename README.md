# Nothing Landing Page

A simple responsive landing page built from the selected Nothing / Bose-inspired design. The page includes a hero section, recommended products, category previews, an about block, and a contact form.

## Технології

- HTML
- SCSS (Sass)
- Vite / Mate scripts for development and build

## Як запустити локально

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть локальний сервер:
   ```bash
   npm start
   ```
3. Для збірки проєкту:
   ```bash
   npm run build
   ```

## Додаткові інструкції

- Стилі пишуться в `src/styles/main.scss` та підключених частинах SCSS.
- Картинки зберігаються в `src/images`.
- Форма у секції Контакти очищується на сабміті без перезавантаження сторінки.
