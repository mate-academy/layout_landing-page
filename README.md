# Landing Page

A single-page adaptive Bike Landing Page, created based on a Figma design. All sections are implemented according to the layout: header with navigation, hero section (“Take the Streets”), “Move Free”, “Compare Bikes”, “The Details”, “Contacts”, and footer.

⸻

Technologies used:

• HTML5 — semantic markup
• SCSS / CSS3 — styling, variables, mixins, responsive design
• BEM — block-element-modifier naming methodology
• Parcel — project bundler
• Git / GitHub — version control
• Figma — design source
